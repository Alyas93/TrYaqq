# ترياق — البناء والحماية والتفعيل

## أولاً: الحقيقة التي يجب أن تعرفها قبل أي شيء

**لا يمكن تشفير ملف HTML تشفيراً حقيقياً.** أي ملف يعمل على جهاز الزبون يجب أن
يفكّه المتصفح ليشغّله، ومعنى ذلك أن مفتاح الفك موجود في الملف نفسه. من يفتح
أدوات المطوّر في كروم يرى الكود بعد فكّه مهما فعلنا.

ما نفعله فعلاً شيئان مختلفان:

1. **التشويش (obfuscation)**: يرفع كلفة النسخ والتعديل من دقائق إلى أيام،
   ويكفي لصدّ صاحب صيدلية أو مبرمج محلي يريد نسخة مجانية. لا يصدّ متخصصاً مصرّاً.
2. **رمز التفعيل الموقّع (ECDSA P-256)**: هذا حقيقي وقوي. لا يستطيع أحد
   **توليد** رمز صالح بلا مفتاحك الخاص، ولو فكّ الملف كله. يستطيع نظرياً تعديل
   الكود ليتجاوز الفحص، لكن ذلك يتطلب فهم الملف المشوَّش، وسيبقى محروماً من
   الذكاء الاصطناعي (يعمل عبر خادمك) ومن التحديثات والدعم.

**القاعدة التجارية**: اجعل قيمة الاشتراك في الذكاء والتحديث والدعم والبيانات
المحدّثة، لا في «الملف». الملف وحده لا يُحمى.

## ١) توليد مفتاحك (مرة واحدة في العمر)

```bash
node tools/license.js keygen     # ينشئ tools/tiryaq-key.json
node tools/license.js install    # يضع المفتاح العام داخل lic.js
```

⚠️ **`tools/tiryaq-key.json` هو رأس مالك.** انقله خارج مجلد المشروع، واحفظ نسخة
على قرص خارجي. من يحصل عليه يصنع رموزاً مثلك. ومن يفقده لا يستطيع إصدار رموز
جديدة للنسخ الموزَّعة (يبقى ما أُصدر عاملاً).

## ٢) بناء النسخة التجارية

```bash
npm i javascript-obfuscator terser        # مرة واحدة
node tools/build.js --pack --obfuscate    # → dist/tiryaq.html
```

| الخيار | ماذا يفعل |
|---|---|
| `--pack` | يعمّي بيانات الأدوية (٦٤٧٨ صنفاً + دليل الأسعار) فلا تُنسخ بالنسخ واللصق |
| `--obfuscate` | يشوّش كود التطبيق: تسمية مبهمة، مصفوفة نصوص مشفّرة، تقطيع النصوص |
| `--min` | تصغير عادي بلا تشويش (للتطوير) |
| `--selfdefend` | حماية إضافية تكسر الملف إن أُعيد تنسيقه (اختبرها جيداً قبل التوزيع) |

بعد كل بناء، شغّل الاختبارات على **النسخة المبنية** لا على المصدر فقط:

```bash
TIRYAQ_APP=dist/app.built.js node tests/pos.test.js
```

## ٣) إصدار رمز لزبون

الزبون يفتح التطبيق → شاشة التفعيل تعرض **رمز جهازه** (مثل `A0E8-B1B8-11A6`)
ويرسله لك بضغطة واتساب. ثم:

```bash
node tools/license.js issue A0E8-B1B8-11A6 "صيدلية النور" 12
```

`12` = عدد الأشهر · `0` = اشتراك مفتوح · و`*` بدل رمز الجهاز = رمز يعمل على أي جهاز
(لا تستعمله إلا للعرض والتجربة).

يطبع رمزاً طويلاً يبدأ بـ `TRQ.` — أرسله للزبون ليلصقه. كل رمز يُسجَّل في
`tools/issued.log` بتاريخه وصاحبه.

للفحص: `node tools/license.js check TRQ.xxx.yyy A0E8-B1B8-11A6`

## ٤) ما يحدث داخل التطبيق

- أول تشغيل: **تجربة ١٢ ساعة** بلا رمز، ويظهر العدّاد في الترويسة (ساعات ثم دقائق).
- بعدها: التطبيق يُقفل خلف شاشة التفعيل (الشاشات والقائمة تختفي).
- الفحص كل ٥ دقائق وعند كل عودة للتطبيق، فلا تمتد التجربة بإبقاء التطبيق مفتوحاً.
- الرمز مربوط بالجهاز وبتاريخ انتهاء، ويُفحص عند كل تشغيل وكل ساعة.
- لا يحتاج إنترنت إطلاقاً — التحقق رياضي محلي.
- تغيير الرمز أو حمولته يُبطله فوراً (التوقيع يكشف أي تعديل بحرف واحد).
